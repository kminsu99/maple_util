GET /maplestory/v1/scheduler/character-state?ocid={ocid}
header: x-nxopen-api-key: {API 키}

※ 실제 호출 결과가 아니라, 페이지 코드가 읽는 필드만으로 만든 예시 응답입니다.
※ 캐릭터·값은 가상이고, 실제 응답에는 여기 없는 필드가 더 있을 수 있습니다.
※ 참고용 파일 (페이지에서 읽지 않음)

필드 설명
- 문자열 'true'/'false' 또는 boolean 모두 올 수 있음 (registration_flag, complete_flag)
- registration_flag: 인게임 스케줄러에 등록한 항목인지 ([인게임 스케줄러 등록 항목만] 필터에 사용)
- type: 'quest' → quest_state 사용 (0 미진행, 1 진행 중, 2 완료)
        그 외   → now_count / max_count 사용 (max_count 0 이면 점수형: now_count > 0 이면 완료)
- cycle (보스): bossDaily / bossWeekly / bossMonthly
- 월드 공유 항목(몬스터파크, 익스트림 몬스터파크, 에픽 던전)은 같은 서버 캐릭터 모두에 같은 값이 옴
